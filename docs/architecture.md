# 아키텍처

변경할 때마다 **근거 숫자**를 함께 남긴다. 숫자 없는 변경은 적지 않는다.

## 현재 구조

```
브라우저 → 로컬 HTTP 서버 (Node 22) → OpenAI
                  ↓
          runs/{label}.jsonl
```

외부 의존은 `openai` 패키지 하나다. HTTP 서버와 SSE 는 Node 내장 모듈로 구현했다.

## 기본값 (기준선)

| 항목 | 값 | 바꾼 근거 |
|---|---|---|
| 모델 | gpt-6-luna | 캐시 할인 90%, 최저가 |
| 히스토리 전략 | full | 기준선 |
| HISTORY_WINDOW | 6 | window/summary 전략에서만 사용 |
| max_tokens | 300 | 출력 길이 변동을 억제해 지연 분산을 줄임 |
| 스트리밍 | 끔 | 기준선. 7주차에 켜서 TTFT 비교 |
| 시스템 프롬프트 | ~1,340 토큰 | 캐싱 최소선 1,024 를 넘기기 위함 |

## 변경 이력

### 2026-10-19 · AWS Lambda → 로컬 서버
실험 8개 중 8개가 로컬에서 성립. 인프라를 쓰면 손잡이 변경마다 배포가 필요해
실험 반복 속도가 떨어진다고 판단. 리더 확인 결과 AWS 사용은 필수가 아님.
포기한 측정축: 콜드 스타트, Lambda 메모리↔CPU, GB-초 비용, API Gateway 29초.

### 2026-10-19 · 시스템 프롬프트 4줄 → ~1,340 토큰
프롬프트 캐싱 최소 프리픽스가 1,024 토큰인데 기존 입력은 턴10에서도 265 토큰이라
`cachedTokens` 가 항상 0이 되는 상태였다. 핵심 지표가 죽어 있었음.
실제 서비스 수준의 프롬프트(역할·레벨·교정 정책·예시)로 교체해 턴1부터 1,373 토큰 확보.

### 2026-10-19 · 모델 gpt-4.1-mini → gpt-6-luna
4.1-mini 는 입력 $0.40 에 캐시 할인 75%. luna 는 입력 $0.10 에 할인 90%.
가격도 싸고 캐싱 효과도 크다. 4.1-mini 는 **할인율 비교축**으로 남겨둔다.

### 2026-10-19 · OpenAI 클라이언트 지연 생성
모듈 로드 시점에 생성하면 API 키가 없을 때 서버가 기동조차 못 했다.
키 없이도 UI 와 /api/scenarios 는 떠야 한다.

## 설계 판단

**세션 상태를 서버에 두지 않는다.** 클라이언트가 history 를 매번 통째로 보낸다.
턴이 깊어질수록 요청 본문과 입력 토큰이 함께 커지는 구조인데, 일부러 이렇게 뒀다.
이 구조 자체가 측정 대상이고, 요청이 서로 독립적이라 **부하 테스트에서 병렬로 때릴 수 있다.**

**시나리오는 시스템 프롬프트 블록 밖에 둔다.** 블록 안에 끼우면 시나리오마다 프리픽스가
달라져 캐시가 깨진다. 공통 블록을 먼저, 가변 부분을 뒤에.

## 알려진 한계

- 합성 history 라 더미 문장이 반복된다. **캐시 적중률이 실사용보다 높게 나올 수 있다.**
  리포트에 명시하거나, 실제 사용 로그를 입력 세트에 섞어 보정해야 한다.
- 응답 길이가 매번 달라 지연이 흔들린다. max_tokens 를 300 으로 고정했지만 완전하지는 않다.
- 로컬이라 콜드 스타트와 인프라 비용 축이 없다.
